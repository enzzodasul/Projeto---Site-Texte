# 👑 ENZZO DA SUL | Official Web Hub

Site oficial e hub de autoridade de **Enzzo da Sul** (Enzzo Marchesotti): Artista, Produtor Musical e Full Stack Developer.

---

## ⚡ Visão do Projeto
Este projeto reúne em uma interface moderna, veloz e imersiva:
- **Top Hits & Ranking:** *Conheço Todos mas Ando com Poucos*, *Favelado*, *Multiplicando*, *Deixa Ela Embrazar*, *Montagem - Empina na Onda*.
- **Trajetória & Vivência:** Raízes na Roda de Funk, produção audiovisual e evolução na tecnologia.
- **Audiovisual:** Videoclipes e sessões ao vivo no YouTube.
- **Full Stack Tech Hub:** Conexão direta com o ecossistema de desenvolvimento (React, TypeScript, Node.js, Python, DIO e Bootcamp Itaú 2026).
- **Canais Oficiais:** Spotify, YouTube, Instagram, GitHub e LinkedIn.

---

## 🚀 Tecnologias Utilizadas
- **HTML5 Semântico & Moderno**
- **CSS3 Avançado (Glassmorphism, Neon Mesh Glow, Responsive Grid/Flexbox)**
- **JavaScript Moderno (ES6+ & Web Audio API para feedback sonoro)**
- **Tipografia:** Syne + Plus Jakarta Sans via Google Fonts

---

## 🌐 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou rodar com uma extensão de Live Server.
